# RA Capitals

Unlisted / pre-IPO shares information platform (catalog with WhatsApp-based enquiries). MVP phase — no payments, no live trading.

## Tech Stack

- MongoDB
- Express
- React (Vite)
- Node

## Getting Started

### Prerequisites

- Node.js
- MongoDB

### Install Dependencies

```bash
# Server
cd backend
npm install

# Client
cd ../frontend
npm install
```

### Run Locally

```bash
# Server (default port 5000)
cd backend
npm run dev

# Client (default port 5173)
cd frontend
npm run dev
```
